# ordi v1.5.2

Fixes the API container failing to start on v1.5.0/v1.5.1:

```
Error [ERR_MODULE_NOT_FOUND]: Cannot find package '@ordi/mcp'
```

v1.5.0 made the API depend on the `@ordi/mcp` workspace package (the hosted
MCP server shares its tool catalog), but the API Docker image never copied
that package in. The development environment always has the whole workspace on
disk, so nothing noticed until the container booted in production. The image
now includes `packages/mcp`.

To stop this class of regression from shipping again, CI builds both Docker
images on every push and boots the API image against Postgres until it
answers `/healthz` – a workspace package missing from the image is now a red
build, not a broken deploy.

## Upgrading

`git pull` and `docker compose up -d --build` as usual. No schema changes;
nothing changed inside the desktop app.
