# ordi v1.1.0

ordi is now open source under the **AGPL-3.0**, and the desktop app updates itself.

## Desktop auto-update

Updates are signed, published to GitHub releases and applied without a manual
download. On launch the app checks for a newer version, stages it in the
background, and offers a restart when it is ready. Only builds signed with the
project's key are accepted.

Because of how Tauri 2 handles permissions, packaged builds until now silently
lacked the capabilities the web layer needed. Declaring them explicitly also
fixes, in the installed app:

- native OS notifications,
- the unread badge on the dock and taskbar,
- the global quick-add shortcut (`Ctrl`/`⌘` + `Shift` + `O`),
- `ordi://` deep links.

Update from v1.0.x by installing this release once; after that, updates arrive on
their own.

## A demo workspace worth looking at

`pnpm db:seed` now creates a workspace that shows what ordi actually does instead
of a handful of empty pages: a live client project with a sprint, labels,
priorities, milestones and real burn-up history; two clients with deals across the
pipeline; invoices that are paid, partly paid and overdue, each posting to the
ledger; logged time with billable and cost rates so project margins are real; and
a knowledge base with content.
