# ordi v1.5.0

Connecting an AI agent is now "log in and approve", and the app and its server
know about each other's version.

## MCP over OAuth: no more token copying

ordi now hosts its MCP server at `<your instance>/api/v1/mcp`. Add that URL as
a remote MCP server in Claude, Cursor or any OAuth-capable client: the browser
opens, you sign in to your own instance, approve on a consent screen, and the
client is connected. Under the hood this is OAuth 2.1 with dynamic client
registration and PKCE (S256 only), single-use ten-minute codes, and loopback
redirects per RFC 8252.

The granted access is an ordinary ordi API token carrying your own
permissions – nothing more – and it appears in Settings → MCP next to
hand-made tokens, revocable with one click. The stdio server with an
`ORDI_API_TOKEN` keeps working for clients without OAuth support.

## Version awareness

The server reports its version in `GET /healthz`, and every client compares it
with its own build:

- a browser tab that survived a server update shows a banner with a one-click
  reload, so nobody keeps working in a stale bundle;
- the desktop app ships its own copy of the UI and updates itself from GitHub
  releases, so it can genuinely run against an older server – when that
  happens it now shows a warning with a link to the update instructions;
- Settings shows the running version at the bottom of the navigation, and
  admins get a link there as soon as a newer release is out (best-effort:
  air-gapped installs simply never see it).

`docs/deployment.md` gained a proper Updating section – the standard cycle is
`git pull` and `docker compose up -d --build`; migrations run automatically.

One caveat: apps older than this release do not carry the check, so the
warning only starts appearing once the desktop app has updated itself to
v1.5.0 or later.

## Upgrading

Migration `0009` adds the two OAuth tables (additive; the Docker image runs
migrations on start). If your reverse proxy only forwards `/api/*`, also
forward `/.well-known/` to the API – the bundled nginx config does this now –
otherwise OAuth discovery cannot complete.
