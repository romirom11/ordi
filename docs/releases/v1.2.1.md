# ordi v1.2.1

Fixes auto-update on macOS, which never actually worked.

## Fixed

- **macOS builds shipped no updater artifact.** Tauri derives the macOS update
  package from the `.app` bundle, and `app` was missing from `bundle.targets` –
  so every release produced a `.dmg` to install by hand but no `.app.tar.gz`,
  and `latest.json` listed only Linux and Windows. Mac clients therefore never
  saw an update, silently.

  Releases from this version on include the macOS updater bundle and its
  signature, and `latest.json` carries `darwin-aarch64` and `darwin-x86_64`.

**If you are on macOS**: install this release by hand once, from the `.dmg`.
Because v1.1.0 and v1.2.0 had no macOS entry in their update manifests, the
already-installed app cannot update itself to this one. After v1.2.1, updates
arrive on their own like they already do on Linux and Windows.
