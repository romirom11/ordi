# ordi v1.40.0

A **Plan** tab that brings milestones and cycles together, cycles you can actually fill, invoices sent from an address of your choice, and a round of Glass polish – including Cyrillic in the Glass typeface.

## Plan: milestones and cycles

The Cycles tab is now **Plan**:

- **Milestones** – what is delivered, and by when – with progress, target dates (red once overdue) and, while a cycle runs, how many of each milestone's tasks it carries. **Pull open tasks into the cycle** takes a milestone's unfinished work into the current cycle in one click.
- **The current cycle** with progress, days left and a breakdown by milestone; upcoming cycles below, completed ones folded away.

Cycles are now **opt-in per project** (project settings → Cycles). New projects start without them; projects that already have cycles keep them. With cycles off, nothing about them shows anywhere.

Cycles also finally work from the app: tasks have a **Cycle** field, the task list filters and groups by cycle, and the bulk bar sets a **Milestone** or **Cycle** on many tasks at once. Before, only the API could put a task into a cycle.

## Project page

- **Settings open in a side panel** from the gear, over the page you were on.
- **The overview leads with the description** as plain text and drops empty blocks: no "no files yet" box, leads only when there are any, and the next milestone in the properties instead of the full list.
- **The Intake tab** appears once intake is switched on or something is waiting in it.
- **The projects list** flags projects marked *At risk* or *Off track* in their latest update.
- In Ukrainian, milestones are now «етапи» throughout.

## Email: several senders

**Settings → Email** (moved out of Integrations) keeps a list of senders, each with its own From address, optional Reply-To and SMTP login. One is the **system** sender (invites, password resets, notifications), one the default for **invoices and quotes**.

- The invoice **Send** dialog has a **From** picker.
- Payment reminders follow up from the address the invoice was sent from.
- Each sender has its own connection test and test email.

Your existing SMTP setting becomes the sender "Default" and keeps doing what it did; `SMTP_URL` in the server env shows as a read-only sender.

## Integrations

Integrations is now a short list – GitHub, Slack, webhooks, each with its state – and each one's setup opens in a side panel.

## Glass

- **Cyrillic in the Glass typeface.** Glass now uses *Urbanist Cyrillic*, Urbanist extended with Cyrillic, so a Ukrainian sentence with English names in it reads as one font.
- **The task view controls float** at the bottom right instead of taking a row under the tabs; the row returns only to show active filters.
- One look for selected things: the active CRM tab and picked filter chips use the same fill as active menu items.
- Settings sections all sit in cards; switches are a calm green; skeletons are a neutral tint; no grey block behind a task description.

## Fixes

- **Invoice PDF from the desktop app** no longer opens a "Not authenticated" page – it downloads with the app's own sign-in.
- **CSV exports** (Settings → Import & export) work from the desktop app too.
- **CRM pipeline cards** have their gap back.
- Dashboard activity reads "changed the integration settings" instead of a raw action name.

## MCP

- `get_project_schema` lists milestones and says whether the project uses cycles.
- `create_task`, `update_task` and `upsert_task` take `milestone` (id or name); `list_tasks` filters by it.
- New tools: `create_milestone`, `update_milestone`, `create_cycle`, `complete_cycle`.
- `send_invoice` goes out from the invoice sender.

After upgrading, reconnect the MCP client so it reloads the tool list.

## Upgrading

One migration, `0042_email_delivery_sender` – a nullable `sender_id` column on `email_deliveries`. It runs on start.
