# ordi v1.23.0

A configuration release: custom fields grow from create-only to a full
management surface, and leads get first-class labels. Plus a company filter
for the leads table and a full-width CRM work queue.

## Custom fields management

- The settings panel could only list and create definitions – a select field
  created there had no way to receive its choices, and nothing could ever be
  renamed, hidden or removed. It now covers the whole lifecycle the API
  already supported: **edit** (label, required, show-in-list, sortable,
  indexed), **deprecate** (hide from records without losing stored values)
  and **delete**, with a confirmation that says out loud that values already
  stored on records survive the definition.
- Select and multiselect fields get an **options editor**: label + technical
  value per option, with the value auto-derived from the label when left
  empty, and a hint that renaming a label is safe while changing a value
  orphans existing records.
- Key and type stay immutable after creation (shown disabled in the edit
  dialog) per the PRD's non-destructive-edit rule – records may already hold
  values under that key.

## Lead labels

- Labels grow a third scoped vocabulary: `lead`, in the same workspace-level
  table and `/labels` endpoints as task and project labels, with a
  `lead_labels` join table behind it.
- The lead page's rail gets the same picker tasks and projects use – search,
  multi-select, creating a label inline – and freezes with the rest of the
  record once a lead converts. The leads table shows label chips next to the
  title.
- `labelIds` rides `POST /leads` and `PATCH /leads/:id`: the API validates
  the ids against the lead vocabulary, replaces the set wholesale on update,
  returns `labelIds` from the list and detail endpoints, and logs label
  changes in the activity trail.

## Smaller things

- The leads tab gains a **company filter** beside search, status and owner –
  `GET /leads` accepted `companyId` all along, the UI just never sent it.
- The CRM **work queue spreads across the full page width** instead of a
  centered column.
