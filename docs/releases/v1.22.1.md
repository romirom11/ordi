# ordi v1.22.1

Two fixes to the CRM pickers shipped in v1.22.0.

## The menu matches the control it drops from

The dropdown was pinned to a fixed width regardless of the field it belonged
to, so a full-width select in a dialog opened a menu half its size: sequence
names like "Секвенція 3: Автоматизація non-tech (email)" wrapped onto two
lines beside empty space. The menu now takes the width of its trigger, with
the previous fixed width acting as a minimum for narrow rail chips.

## Opening one picker closes the last

Clicking another field inside a dialog left the previous menu hanging open
over it. The outside-click listener ran in the bubble phase, and the dialog
panel stopped `mousedown` before it ever reached the document; it now runs in
the capture phase, and the panel's redundant `stopPropagation` is gone (the
backdrop already only closes on clicks that land on itself).
